# research-scope.md — 研究范围与口径（工作版）

> 本文件是「要测量什么」的权威来源。状态标签：**已确定 / 试行 / 待核实 / 待讨论 / 不适用**。

## 1. 研究对象与单位

- 研究主题：中美企业一级市场估值差异，及一级估值与上市后二级价格的关系（来源：任务说明「项目3」）。
- 研究对象：有可核验「一级市场股权定价」记录的中国企业与美国企业。
- **一行数据代表什么**：一次「企业 × 融资轮次/估值时点」的可核验估值观测。**试行**，待讨论是否改为「企业-轮次」或「企业-事件」粒度。
- 主键（候选）：企业唯一标识 + 轮次标识 + 估值时点。

## 2. 核心问题（已确定，来自任务说明）

1. 中美可比企业是否存在稳定的估值差异？
2. 收入、利润、成长性、技术能力、投资者类型如何进入估值？
3. 一级市场估值能否预测 IPO 定价与上市后表现？
4. 二级市场估值变化是否影响私营企业后续融资定价？

> 本阶段以 **Q1 的描述性比较**为最小可交付目标；Q2–Q4 依赖更多数据，列为后续。仅做描述性比较，不做因果断言。

## 3. 关键概念的操作性定义

### 3.1 可比企业（待讨论）

「可比」的最低条件候选维度：

| 维度 | 候选口径 |
| --- | --- |
| 行业 | GICS 或申万/证监会行业，二级或三级（待定） |
| 商业模式 | 按收入来源 / 价值链位置粗分类（分类法待定） |
| 发展阶段 | 融资轮次区间（种子/天使/A–C+/Pre-IPO/已上市） |
| 规模 | 收入区间或估值区间（阈值待定） |

判定「可比」= **人工确认 + 自动候选**；自动候选仅作初筛，不得直接写为已确认。

### 3.2 估值口径（试行）

- **投前 / 投后**：必须显式标注，二者不可混算。
- **币种**：记录原始币种 + 统一折算币种（建议美元为基准，人民币按披露汇率或当日汇率折算，**待核实**）。
- **单位**：统一为百万（M）或十亿（B）美元/人民币，显式声明。
- **时间口径**：估值日期、交易日期、披露日期分开记录，不混用。

### 3.3 一级 vs 二级（试行）

- **一级市场估值**：融资轮次披露估值（招股书、融资公告）。
- **IPO 定价**：发行价 / 定价区间。
- **上市后二级价格**：收盘价、发行后 N 日价格（观察窗口**待讨论**：首日 / 首月 / 3 个月 / 6 个月）。
- 三者分开为不同字段。

### 3.4 估值字段规格（已落地，见 src/valuation_models.py）

一次估值观测的字段：`valuation_amount`（万元）+ `valuation_currency` + `valuation_stage`（投前/投后/评估/IPO定价/上市价）+ `valuation_basis`（披露/评估/价格×股本/市盈率）+ `price_per_share` + `total_shares`（回算输入）+ `evidence_text` + `source_page`。

规则：原文直接披露估值填披露值；只有价格没有总股本**不硬凑**，`valuation_amount` 留空标「待核实总股本」。真实样例见 docs/initialization-check.md。

## 4. 样本边界与阶段顺序

- **阶段顺序（已确定，导师决定）**：先做国内企业的一级市场估值 → 美国企业数据用已购 PitchBook 后续做中美比较。
- 时间：**待核实**（建议聚焦近年，以数据可得性为准）。
- 地区：**第一阶段＝国内企业**（中国，含港澳？**待讨论**）；美国企业为第二阶段，数据来自 PitchBook。
- 行业：**待讨论**（先聚焦可比性强、招股书披露充分的行业，如科技 / 消费 / 医疗，待定）。
- **纳入标准**：有可核验一级估值记录 + 有对应可比企业 + 行业/阶段可标注。
- **排除标准**：无披露估值、无法核实、SPAC / 借壳等特殊结构（是否单列，**待讨论**）。
