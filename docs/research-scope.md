# research-scope.md — 研究范围与口径（工作版）

> 本文件是「要测量什么」的权威来源。状态标签（对齐指南四类未知标记）：**已确定 / 待确认 / 假设 / 证据不足 / 不适用**。其中「假设」＝为小样本试验暂用的口径，「待确认」涵盖待核实/待讨论/待定，「证据不足」＝已有候选信息但不足以确认。
> 本文件覆盖《文档与 AGENTS.md 撰写指南》第五部分「项目三至少讨论」的 8 项（见末尾对照表）。

## 1. 研究对象与单位

- 研究主题：中美企业一级市场估值差异，及一级估值与上市后二级价格的关系（任务说明「项目3」）。
- 研究对象：有可核验「一级市场股权定价」记录的中国企业与美国企业。
- **一行数据代表什么**：一次「企业 × 融资轮次/估值时点」的可核验估值观测。**假设**。
- 主键（候选）：企业唯一标识 + 轮次标识 + 估值时点。

## 2. 核心问题（来自任务说明）

1. 中美可比企业是否存在稳定的估值差异？
2. 收入、利润、成长性、技术能力、投资者类型如何进入估值？
3. 一级市场估值能否预测 IPO 定价与上市后表现？
4. 二级市场估值变化是否影响私营企业后续融资定价？

> 本阶段以 **Q1 的描述性比较**为最小可交付目标；Q2–Q4 依赖更多数据，列为后续。**仅做描述性比较，不做因果断言（已确定）。**

## 3. 关键概念的操作性定义

### 3.1 可比企业（已落地，工作版）

**最低条件（四维，分两级）：**

| 层级 | 维度 | 工作口径 |
| --- | --- | --- |
| **硬匹配（缺一不可）** | 行业 | 自定义赛道标签 `sector` 大类 + `subsector` 细分（回源招股书主营），已落 `samples/company_master_cn.jsonl`（16 家）；第一阶段聚焦估值披露充分的赛道（半导体、生物医药、汽车零部件等，依据 2026-10-08 摸底） |
| | 发展阶段 | 融资轮次区间：种子/天使 / A–C+ / Pre-IPO / 已上市；已落样本 `event_type`/`stage_label` 字段（仅融资事件打阶段，非融资标 n_a） |
| **次级对齐（同行业内排序）** | 商业模式 | 按价值链位置粗分类（设计 / 制造 / 平台 / 服务，**假设**） |
| | 规模 | 收入区间或估值区间（阈值**待定**） |

判定「可比」 = **人工确认 + 自动候选**；自动候选仅按「行业 + 阶段」初筛，不得直接写为已确认。国内×国内候选对已由 `src/comparable_matching.py` 生成（25 对，一律标「候选」，见 `samples/comparable_pairs_cn.jsonl`）。

### 3.2 估值口径（假设）

- **投前 / 投后**：必须显式标注，二者不可混算。投后 = 投前 + 本轮融资金额（示例：摩尔线程投前 246.20 亿 + 融资 52.25 亿 ≈ 投后 298.45 亿，回算需标注非披露）。
- **币种**：记录原始币种 + 统一折算币种（建议美元为基准，人民币按披露汇率或当日汇率折算，**待核实**）。
- **单位**：统一为万元（本币），比较时再折算；显式声明。
- **时间口径**：估值日期（基准日）、交易日期（成交/工商变更）、披露日期分开记录，不混用（见 3.3）。

### 3.3 五个价格/时点口径的区分（假设）

同一家企业会有多个「价格」概念，schema 里必须各自独立成字段、不得混用：

| 概念 | 字段 | 定义 |
| --- | --- | --- |
| 融资轮次/事件 | `round_label` | 增资/转让/改制/股权激励等事件标签 |
| 交易日期 | `event_date` | 成交或工商变更日期 |
| 估值日期 | `valuation_date` | 评估报告/估值报告的基准日 |
| IPO 定价 | `valuation_stage=ipo_price` | 发行价 / 定价区间 |
| 上市后二级价格 | `valuation_stage=listed_price` | 收盘价，观察窗口见下 |

**上市后观察窗口（假设）**：首日收盘 + 30 日；可选 90 / 180 日。窗口最终口径**待讨论**。

### 3.4 缺失、区间与不同披露口径的记录（假设）

- **缺失估值**：原文未披露且无法回算 → `valuation_amount` 留空，标「待核实」，不硬凑。
- **区间/上限估值**：如「投前不高于 45 亿」→ `valuation_amount` 记上限 45 亿，`notes` 标注「区间/上限，非精确成交价」；「投前 25 亿」为精确值则直接记。
- **不同披露口径**：`valuation_basis` 分 `disclosed`（原文直接披露）/ `appraisal`（评估报告）/ `price_times_shares`（价格×股本回算）/ `pe_multiple`（市盈率回算）；`data_source` 分 `pdf_disclosed` / `calculated` / `inferred`。
- **条款目标估值降权**：如沐曦「回购条款中投前 170 亿」非成交价，`notes` 标注并在下游统计中排除或降权。

### 3.5 中美企业匹配（国内候选对已落地，中美待第二阶段）

- **自动候选**：行业标签 + 发展阶段 + 规模区间 → 生成候选对（一家中国企业 × ≥1 家美国候选）。国内×国内候选对已跑通（`samples/comparable_pairs_cn.jsonl`），中美匹配复用同一逻辑（`country` 字段已就绪）。
- **人工确认证据**：招股书「可比公司」章节、主营构成、行业分类；三者至少两项一致才确认。
- **匹配关系**：可多对一（多家美国企业对应一家中国企业），每条匹配记录置信度（`候选 / 已确认`）。
- 本阶段**先做国内**（DEC-004），中美匹配为第二阶段（PitchBook 到位后）。

### 3.6 估值字段规格（已落地，见 src/valuation_models.py）

一次估值观测的字段：`valuation_amount`（万元）+ `valuation_currency` + `valuation_stage`（投前/投后/评估/IPO定价/上市价）+ `valuation_basis`（披露/评估/价格×股本/市盈率）+ `price_per_share` + `total_shares`（回算输入）+ `evidence_text` + `source_page`。

规则：原文直接披露估值填披露值；只有价格没有总股本**不硬凑**。真实样例见 docs/initialization-check.md 与 samples/valuation_sample_cn.jsonl。

## 4. 样本边界与阶段顺序

- **阶段顺序（已确定，导师决定 DEC-004）**：先做国内企业的一级市场估值 → 美国企业数据用已购 PitchBook 后续做中美比较。
- 时间：**待核实**（建议聚焦近年，以数据可得性为准）。
- 地区：**第一阶段＝国内企业**（中国，含港澳？**待讨论**）；美国企业为第二阶段，数据来自 PitchBook。
- 行业：第一阶段聚焦估值披露充分的赛道（半导体/检测/产业互联网等，**假设**）。
- **纳入标准**：有可核验一级估值记录 + 有对应可比企业 + 行业/阶段可标注。
- **排除标准**：无披露估值、无法核实、SPAC / 借壳等特殊结构（是否单列，**待讨论**）。
- **样本损失报告（假设）**：每个处理阶段记录「纳入 → 流失」数量：候选企业 → 有估值记录 → 可比匹配成功 → 进入比较；匹配失败与不可比样本**保留**并在结果中报告，不静默删除。

## 5. 计划产出

- 中美企业估值数据库（企业-轮次-估值观测 + 可比对）。
- 典型案例与事实报告。
- 条件成熟后：描述性比较与计量分析（仅描述性，不做因果断言）。
