## 2. 字段（工作版）

核心字段（一行 = 一次估值观测，Schema 见 [src/valuation_models.py](../src/valuation_models.py)）：

- 企业标识、名称消歧键（中文/英文/历史名/统一社会信用代码）
- 国别、行业、商业模式分类、发展阶段/轮次
- 估值额、币种、投前/投后/评估/IPO定价/上市价（`valuation_stage`）
- 估值依据（披露/评估/价格×股本/市盈率，`valuation_basis`）
- 估值日期、交易日期、披露日期
- 来源、披露页码/链接、可比对标识、置信度（候选/待核验/已确认）

已落地样例：[samples/valuation_sample_cn.jsonl](../samples/valuation_sample_cn.jsonl)（26 条真实记录，Pydantic 校验 26/26 通过）。

## 3. 处理层级与存储

`raw`（原始，只读）→ `staging` → `work`（中间产物）→ `curated`（可复用）→ `results`（结论）。

- 原始数据、大文件**不提交 GitHub**；只提交文档、Schema、小型测试样例。
- 原始数据只读保存，不覆盖原路径。
- 分层保存：修正版新增版本，不覆盖旧版本。

## 4. 版本与校验

- 命名：`dataset/v1`；每次修订 +1 版本，不覆盖旧版本。
- 校验：Manifest（清单）、Schema（字段）、Quality（检查报告）、文件哈希。
- 质量检查：范围、唯一性、抽样复核、投前/投后一致性、币种口径一致性。
