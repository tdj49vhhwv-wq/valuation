# runtime-and-runbook.md — 运行手册（工作版）

> 让另一位成员能按本文件完成一次小规模运行；当前文档阶段尚无代码运行需求。

## 1. 运行环境

- **待确认**：本地 Runtime / 腾讯云 Runtime / 混合，及原因。
- 当前阶段仅需文档编辑，无代码依赖。

## 2. 输入与输出

- 输入：候选招股书 / 融资记录（版本见 docs/data-management.md）。
- 输出：结构化估值观测表（staging / curated）+ 质量检查报告。

## 3. 第一项任务（小样本 dry-run 流程）

1. 读 README.md、AGENTS.md、research-scope.md、data-management.md；
2. 选 1 份公开招股书样例（**先国内**：A 股 / 港股招股书）；
3. 提取「企业-轮次-估值额-币种-投前/投后-来源页码」；
4. 由另一位成员或人工复核；
5. 报告：来源、字段、缺失项、待核实项。

## 4. 质量检查

- 投前/投后是否显式标注；币种/单位是否统一；来源是否可回到原文。
- 范围、唯一性、抽样复核（见 data-management.md 第 4 节）。

## 5. 中断、失败与恢复

- 失败时保留中间结果与日志；从最近检查点重跑；不覆盖 raw。
- 发现错误保留旧版本并发布修正版。

## 6. 交付

- 结果上传、登记方式：正式结果进 docs/ 或 results/；数据版本与哈希记录于 data-management.md。
